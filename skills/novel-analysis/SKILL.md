# 分析、评阅与包装任务

## 一、小说分析

分析小说文本（用户提供或用户指定的作品片段）时输出：

```
## 主题与题材
（核心主题、题材类型、对标作品）
## 结构分析
（叙事结构、主线支线、节奏分布、钩子设置）
## 人物分析
（主要人物的欲望/恐惧/弧光、关系网络）
## 文笔与风格
（叙述距离、句式节奏、对话风格、描写习惯）
## 亮点与短板
（各 3 条，引用原文佐证）
## 可借鉴点
（对用户自己作品 applicable 的做法）
```

要求：结论必须有原文引用佐证；不做泛泛而谈的文学评论。

## 二、拆书学习

拆解爆款/优秀作品时聚焦四个层面，产出“可复用的结构”而不是情节复述：

1. **结构层**：开篇钩子怎么设（前 300 字/1000 字发生了什么）、爽点周期多长、每章钩子类型分布。
2. **节奏层**：压爽比（铺垫与释放的篇幅比例）、章节字数分布、高潮间隔、缓冲章怎么写。
3. **人物层**：主角欲望与恐惧、配角功能定位、反派行为逻辑是否自洽、人物出场方式。
4. **文风层**：叙述距离、对话密度、描写习惯（可回流给文风卡——按《novel-project》的文风卡格式更新）。

输出格式：每层一节，先结论后原文证据，最后给“迁移清单”——哪些做法可以用到什么类型的书上。

## 三、作品评阅（结构化评分制）

评阅作者稿件时扮演资深网文金牌编辑——犀利直接、说网文圈行话、目标是帮作者赚钱（爆款逻辑），不写学院派文学评论。

**评分维度**（每维含：查什么 / 扣分点 / 诊断示例）：

1. **钩子（开篇留存）**：查前 300 字有无异常/危机/金手指、前 1000 字有无第一次冲突或强悬念、章尾钩子是否成立。扣：开局写日常、慢热铺垫、环境铺陈开局、钩子靠抒情不靠事件。
2. **爽点（情绪节奏）**：查每章有无情绪点、压→转→爽→钩是否闭环、爽点释放是否具体可感。扣：连续多章无爽点、爽点过夜不释放、写“他变强了”式空泛释放。
3. **人设（代入感）**：查主角欲望与行动力、配角功能明确、反派动机自洽。扣：主角被动/圣母/降智、系统代打、反派无脑送人头。
4. **信息与连贯**：查设定交代方式（拆碎进剧情 vs 大段灌输）、前后文一致、伏笔有铺设有回收。扣：开章设定灌输、前后矛盾、吃设定。
5. **文笔与排版**：查对话占比与口语度、长短句节奏、段落呼吸感、AI 味（对照《novel-prose-standards》铁律）。扣：书面腔对话、句式均匀无变化、堆砌形容。
6. **人味（活人感专项）**：查角色说话是否像真人（有口癖/停顿/答非所问）、情绪是否有来处、反应是否多样。扣：人均情绪稳定发言、问答完美对齐、反应模板化。

**输出格式**：

```
## 总评
【段位】+ 分数（100 制）+ 一句话核心诊断
（段位：≤35 扑街稿 / 36-50 修修能看 / 51-75 过稿线 / 76-90 精品 / 91-100 爆款相）
## 分项扒皮
（按六个维度逐项：得分 + 直接点问题——缺啥、水了几字、哪句人设崩了，引用原文位置）
## 改稿示范
只选全文最烂的一段，按爆款硬指标改写：加冲突、删废话、融一个贴合剧情的网络热梗（自然不硬塞）。
改后与原文等长，并逐条说明改了什么、为什么。
```

**纪律**：改稿示范只聚焦最烂一段（集中火力，不平均用力）；总评控制在 2000 字内；按番茄爆款公式定制标准，其他平台（起点/晋江）按平台调性微调权重。

**章节评分与取名（成稿后的标配收尾，源自市场最高均热品类）**：对单章成稿执行一体化收尾——
1. **评分**：按上文六维打分（百分制 + 段位）。
2. **毒点分析**：对照《novel-plotting》毒点防火墙逐条检查本章。
3. **章节名**：生成 7 个适配本章内容的候选章节名（悬念型/爽点型/反差型/直白型分布），各配一句点击率理由，标出推荐。
4. **修改建议**：按严重度列 3-5 条，每条附具体改法与示例句（原文 → 改后）。
输出顺序：评分 → 毒点 → 章节名 → 修改建议。

## 四、模拟读者团试读

组织多位典型读者读完章节，给真实读者视角反馈。**你不是编辑——编辑看技术，读者看爽不爽、追不追。完全代入读者视角，说糙话，不打官腔。**

读者团成员（默认取前 4 个，可按题材加第 5 个）：
1. 快节奏白嫖党：手机上划得飞快，三行没爽点就退出去；说话直接：“这段磨叽了”“这里爽到了”。
2. 付费老书虫：同题材追过几十本，套路全见过，最烦注水和降智；会拿别的书对比。
3. 题材新读者：第一次看这类书，前情不熟；会问“这人是谁”“这设定啥意思”（前情不清就是问题）。
4. 逻辑挑刺型：专抓人物降智、前后矛盾、行为不合理；说话不客气但说的都是实的。
5.（可加）女性向/男性向读者：按题材选择。

输出格式：
```
## 读者反馈
（每位读者一小节：【身份】+ 三五句大白话反馈，标出【爽点】【无聊点/想弃书处】【看不懂处】【追更意愿：追/弃/观望】。引用原文位置，具体到段落）
## 汇总
（最该改的 3 个问题，按严重度排序，各配一句修改方向；最后一句“会不会追更”的总体判断）
```

## 五、平台合规体检

按中文网文平台内容规范审查稿件，目标是**帮作者顺利过审同时保住剧情张力**——给“怎么改能过”的方案，不是一刀切删除。

检查类别：
1. 色情低俗：露骨性描写、过度身体细节（平台尺度差异：晋江/番茄严，起点/纵横相对宽松）。
2. 暴力血腥：酷刑/虐杀的过程细节、血腥渲染过度。
3. 涉政涉敏：真实政治人物/事件/机构的影射与讨论、敏感历史评价。
4. 违法细节教学：可被模仿的作案、制毒、自杀等具体方法与步骤。
5. 价值观风险：美化犯罪、宣扬仇恨、歧视性言论。
6. 未成年人相关：未成年角色涉性涉暴内容。
7. 侵权风险：真实人名/品牌/作品的不当使用、高度模仿知名桥段。

输出格式：
```
## 风险清单
（每条：【位置】【类型】【等级：高/中/低】【修改建议】；按等级排序。无风险的类别不列；全文无风险时明确写“未发现明显风险，可正常发布”）
## 整体结论
（一句话：可发布 / 建议修改后发布 / 有封禁风险必须修改）
## 合规改写版（用户要求时）
（保留剧情张力与信息量的前提下，把风险表达模糊化、艺术化或替代；附逐处改写说明）
```

## 六、起名

为角色/地点/组织/功法/法宝/书名/章节名起名时：

1. 先收集约束：题材与世界观基调、已有命名的风格惯例（音节长度、中外感、文白程度）、避讳名单。
2. 批量生成（默认 8-12 个），分组呈现，每组标注思路。
3. 检查：与已有名字是否混淆（读音/字形）、是否撞名知名作品、生僻字是否影响阅读。
4. 书名另加：题材关键词 + 爽点暗示 + 平台检索友好度分析；给一句话简介配套。

输出格式：分组列表 + 每个名字一行“名字 — 思路/寓意”，最后给 2-3 个推荐组合。
