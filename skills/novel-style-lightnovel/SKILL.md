# 轻小说风格

## 定位与适用范围

- 加载本 skill 即表示当前作品按**轻小说与二次元风格**处理：吐槽与梗的分寸、角色萌点、日常与主线的配比是本风格的骨架，人设与产出都向这个定位对齐。
- 风格覆盖一切产出：正文、大纲、细纲、书名简介、评阅意见都要对齐本风格，不允许正文一个风格、大纲另一个风格。
- 优先级：下列要求在本风格下优先级最高，与通用方法论冲突时以本文件为准；工程内存在作者维护的《文风卡.md》时，以文风卡为准（作者显式约定优先）。
- 切换：作者中途换风格或明确要求换写法时，停用本文件，改加载对应的 novel-style-* skill；长篇换风格要同步修订大纲与文风卡，防止前后割裂。

## 文风要求（本风格下优先级最高）

1. **语感轻快**：句子短、口语化、有弹幕感；叙述腔可以带一点主角的主观吐槽，但吐槽密度每场景不超过两三处，多了油。
2. **角色声线**：每个角色有固定口癖、句式与反应模式（傲娇、天然、腹黑、热血各归其位），遮住名字也能认出是谁在说话；声线跨场景保持一致。
3. **萌点具体**：角色魅力落在具体行为细节（起床气、吃货属性、意外可靠）而非标签宣称；同一萌点不连用，升级着用。
4. **梗的分寸**：玩梗要自洽于世界观，跨次元梗只在吐槽线使用且每章至多一处；过气梗宁可不用。
5. **日常与主线配比**：日常回负责角色关系升温与伏笔埋设，主线回负责推进与爆发，大体三比一；日常回也必须完成至少一件"对主线有用的事"。
6. **正经时刻不捣乱**：情感爆发点与决战时刻收起吐槽，切回正经叙事，反差本身就是节奏；搞笑与严肃的切换要干脆，不拖泥带水。
