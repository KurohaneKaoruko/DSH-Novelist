# 科幻末世风格

## 定位与适用范围

- 加载本 skill 即表示当前作品按**科幻与末世题材**处理：设定推演、硬核细节的分寸、废土生存与人性抉择是本风格的骨架，人设与产出都向这个定位对齐。
- 风格覆盖一切产出：正文、大纲、细纲、书名简介、评阅意见都要对齐本风格，不允许正文一个风格、大纲另一个风格。
- 优先级：下列要求在本风格下优先级最高，与通用方法论冲突时以本文件为准；工程内存在作者维护的《文风卡.md》时，以文风卡为准（作者显式约定优先）。
- 切换：作者中途换风格或明确要求换写法时，停用本文件，改加载对应的 novel-style-* skill；长篇换风格要同步修订大纲与文风卡，防止前后割裂。

## 文风要求（本风格下优先级最高）

1. **设定推演先行**：核心设定（技术原理/灾变机制/社会形态）动笔前完成推演并写入设定集，正文只展示结果与影响，禁止大段设定说明书；每个超常设定都要回答"那为什么没人早这么做"。
2. **细节颗粒度**：技术细节给到"可感知的具体"（仪表读数、弹药余量、空气过滤器的寿命），不给伪术语堆砌；一个准确细节胜过十个生造名词。
3. **末世压力常在**：资源 scarcity 贯穿日常（水、食物、燃料、药品、安全屋），每次消费都是决策；舒适是例外，紧绷是常态。
4. **人性抉择驱动剧情**：道德困境（救谁、牺牲谁、信谁）是核心引擎，抉择要有真实代价且不可反悔；禁止主角光环消解困境。
5. **科学克制**：用"已知科学的延长线"写未知，避免明晃晃违背守恒律；确需超纲设定时，用一致的内部规则补足并在设定集中标注。
6. **冷静克制的叙述腔**：末世叙事默认冷静白描，情绪藏在细节与动作里，惨烈场景不渲染形容词，用事实的重量压住读者。
