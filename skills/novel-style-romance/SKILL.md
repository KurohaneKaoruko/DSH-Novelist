# 甜宠言情风格

## 定位与适用范围

- 加载本 skill 即表示当前作品按**女频甜宠言情**处理：心动瞬间设计、糖点节奏、双视角拉扯与情感线长线管理是本风格的骨架，人设与产出都向这个定位对齐。
- 风格覆盖一切产出：正文、大纲、细纲、书名简介、评阅意见都要对齐本风格，不允许正文一个风格、大纲另一个风格。
- 优先级：下列要求在本风格下优先级最高，与通用方法论冲突时以本文件为准；工程内存在作者维护的《文风卡.md》时，以文风卡为准（作者显式约定优先）。
- 切换：作者中途换风格或明确要求换写法时，停用本文件，改加载对应的 novel-style-* skill；长篇换风格要同步修订大纲与文风卡，防止前后割裂。

## 文风要求（本风格下优先级最高）

1. **心动可感**：每一次心动都要落在具体感官细节上（指尖相触、呼吸停顿、耳尖发红），不用"心里一颤"这类套话反复交差；同一对 CP 的心动写法要随关系进展升级。
2. **糖点节奏**：每章至少一个糖点（互动/独处/守护/吃醋/告白进阶），糖点之间用事业线或友情线调节浓度；糖中要带一点拉扯（差一点说破、被 Interrupt 打断），直给的糖要留给关键节点。
3. **双视角与信息差**：适当切入男主视角写他的克制与在意，制造"读者知道她不知道"的甜；信息差是张力来源，解除信息差要挑在最疼的位置。
4. **误会分寸**：禁止为虐而虐的降智误会；误会有合理动机、有时限、不过夜拖三章；解开误会的方式要靠沟通或事件，不靠巧合。
5. **情话与对话**：情话要口语化、带人物性格烙印，禁止网络流行语直接搬用；对白要有潜台词，说的和想的不完全一致才动人。
6. **日常质感**：甜品、宠物、天气、季节这些日常元素要服务情绪而非凑字；女主要有自己的事业与朋友，不做恋爱脑。
