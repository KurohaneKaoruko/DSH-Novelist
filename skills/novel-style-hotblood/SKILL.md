# 热血爽文风格

## 定位与适用范围

- 加载本 skill 即表示当前作品按**男频热血爽文**处理：升级流、打脸四拍、爽点升级链与期待感管理是本风格的骨架，人设与产出都向这个定位对齐。
- 风格覆盖一切产出：正文、大纲、细纲、书名简介、评阅意见都要对齐本风格，不允许正文一个风格、大纲另一个风格。
- 优先级：下列要求在本风格下优先级最高，与通用方法论冲突时以本文件为准；工程内存在作者维护的《文风卡.md》时，以文风卡为准（作者显式约定优先）。
- 切换：作者中途换风格或明确要求换写法时，停用本文件，改加载对应的 novel-style-* skill；长篇换风格要同步修订大纲与文风卡，防止前后割裂。

## 文风要求（本风格下优先级最高）

1. **爽点密度与升级链**：每章至少一个清晰爽点（打脸/突破/获得/扬名），爽点沿"憋屈—蓄力—爆发—余韵"四拍展开；主角能力与地位沿升级链爬升，每一环都要兑现上一环埋下的期待，不空许诺。
2. **期待感管理**：每章结尾必须留钩子（新危机/新目标/新悬念/即将打脸），断章断在情绪最高点前一步；下一章开头迅速接住，不注水。
3. **打脸要打得响**：反派立得住（够嚣张、够具体），铺垫足（让读者憋到位），打脸过程干脆利落有围观视角，事后有余韵（旁人反应、地位变化）。禁止主角自证，让事实与旁人反应替他说话。
4. **金手指有代价有成长**：金手指的使用要有规则与限制，随剧情解锁新用法；禁止一键无敌解决一切冲突。
5. **战斗与突破写法**：战斗写策略与应对，不写招式名词堆砌；突破写身体感受与天地异象的具体画面，篇幅克制不拖沓。
6. **节奏铁律**：开篇三行内进入冲突或事件；每 500 字左右要有一个信息增量或情绪增量；连续两段没有推进就删一段。
