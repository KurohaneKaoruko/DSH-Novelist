# 场景与对话写作技法

## 一、场景三拍结构

每个完整场景（章节内的一个叙事单元）由三拍构成：

1. **入场（约 10%）**：地点、在场人物、初始状态，用一个具体动作或感官细节切入，不用环境说明书。
2. **对抗（约 70%）**：场景目标遭遇阻力。阻力来自冲突（对手、环境、内心），每 2–3 拍升一级；对话与动作交替推进，穿插最少量的必要描写。
3. **收束（约 20%）**：场景结果 + 情绪落点 + 通向下一场景的钩。结果必须改变局面（信息、关系、资源、位置至少一项变化），没有变化的场景删掉。

一章通常 2–4 个场景；场景切换用空行或明确的转场句，转场必须交代时间/地点变化。

## 二、对话写作技法

- **对话三功能**：推进剧情、暴露人物、制造张力。一段对话至少占一项，三项不占的寒暄删掉。
- **区分度**：用词层次（文雅/粗俗/行话）、句长习惯（急促短句/啰嗦长句）、口癖（语气词、称呼、口头禅）——遮住名字能认出谁在说。
- **潜台词**：人物经常言不由衷：谈判、试探、掩饰、反讽。写“说的”和“想的”的落差，不写心理解释。
- **答非所问**：真实对话经常跑偏、抢话、误解；一问一答完美对齐是 AI 腔。
- **信息控制**：不通过对话灌输设定（说明书腔）；必要背景用动作带出（他擦了擦剑：“这剑跟了我十年。”）。
- **对话标签**：多数时候用“说”，或者干脆用动作代替标签；禁止“愤怒地说”“惊讶地问”这类情绪副词标签。

## 三、人物出场设计

- 重要人物出场三要素：差异化的第一动作（而非外貌罗列）、一句话立住性格、与主角产生即时关系（冲突/利益/情感）。
- 外貌描写分散在动作里给，不一次性倒完；只写 1–2 个最有记忆点的特征。
- 配角出场即定功能：导师/对手/损友/情报源，功能完成了就退场，不加戏。
- 反派出场前先立威（借他人之口的传闻、既往事迹），出场时的行事逻辑必须配得上传闻。

## 四、爽点与打脸设计

**三段式爽感闭环**：任何爽点都遵循“压抑 → 蓄势 → 释放”——压抑要具体（越具体释放越爽）；蓄势是主角隐忍/布局/觉醒（番茄类 1–2 章内必释放，起点类可铺 3–5 章）；释放把爽感外显写足（数字、对比、旁人反应）。

**打脸四拍**（打脸桥段的标准结构，新手最容易漏第四拍）：
1. **嘲讽**：反派/众人看不起主角，越嚣张越好。
2. **沉默**：主角不辩解，淡淡出手（蓄势的张力）。
3. **碾压**：实力/真相/反转一击致命。
4. **围观**：旁观者的震惊反应——**这一拍最容易被漏掉，但最爽**；围观台词越短越狠，两三个字胜过一句完整话（“完了。”“就这水平？”）。

**爽点升级链**（防原地重复疲劳）：同一种爽点不能原地重复，必须升级对象/规模/方式——打脸同窗 → 长辈 → 宗门 → 天才 → 大势力 → 天道。设计前先问：上一次同类爽点的量级是多少？这次要更高。

**频道差异**：男频重实力碾压、越级挑战、围观惊呼；女频重情绪解气、体面打脸、让瞧不起我的人后悔。

**语言指纹（speech_profile，防“所有人一个腔”）**：每个主要角色记一张——风格（粗/雅/毒舌）+ 口癖 + 句长偏好 + 常用词 + **绝不会说的词**。自检每句对话：“只有这个角色会这么说吗？”写对话前对照指纹注入（存人物卡，见《novel-project》模板）；长篇每隔几卷抽查一次指纹是否还守得住。

## 五、常见场景类型要点

- **打斗**：节奏优先，短句短段；每回合有攻防转换与代价；写痛感与疲惫，不写招式名称堆砌；胜负手来自前文铺垫的细节（地形、道具、心理战），不临场开挂。
- **情感戏**：用具体物件与动作承载情绪（旧照片、留着的餐具、迟到的回复），直白的心理独白降到最低；情绪推进有台阶，不许一步到位。
- **日常/过渡戏**：承担人物关系展示或伏笔铺设，否则删；控制在半章以内，插一点幽默与生活质感。
- **悬念戏**：信息释放节奏是全部：给一半、错位给、借不可靠视角给；章节结尾停在最想让人追问的地方。
- **升级/收获戏**：爽点要具体量化（等级、数量、能力清单），配合旁人反应放大；立刻展示一次新能力的用途，不留账。

## 六、情绪曲线设计

- 章级曲线：开头承接上文情绪 → 中段主冲突推进（情绪走高或压低）→ 转折点 → 结尾钩子落在情绪峰值或强烈余韵上。
- 卷级曲线：小高潮渐次抬高，大高潮前压到最低（至暗时刻），卷末释放 + 跨卷钩。
- 情绪对比原则：爽前要压、悲前要甜；连续同类情绪会麻木，交替安排。
- 每章写完检查一遍曲线：把每拍的情绪标成曲线，看是否有平台期（连续同强度）与断裂处（无过渡的跳变）。

## 七、描写纪律

- **五感模型与色彩档案**：为每个重要场景建立“色彩锚点”——用 1-2 个具体的色彩/光影意象固定场景气质（如雾灰×灯光黄对应阴郁旧城，暖橙×白对应日常治愈），全文同类场景色彩一致，读者靠色彩就能认出“回到了哪个世界”。五感轮换：视觉为主，穿插听觉/触觉/嗅觉/味觉；不五种感官每段全上。
- 描写为当下情绪服务：紧张时写声音与时间感，悲伤时写光线与温度；删掉与情绪无关的景物罗列。
- 移动镜头：人物动、镜头跟着动，不用摄像机式全景扫描。

## 任务流程

**场景写作**：把场景要点（地点/人物/目标/冲突/结果）扩写为完整场景，按三拍结构组织（入场 10% → 对抗 70% → 收束 20%）。可结合文风卡对齐语言风格。输出纯正文。

**黄金三章/开篇**：为新书或新卷写开篇章节。硬指标：前 300 字交代主角身份处境并抛出异常/危机/金手指；前 1000 字第一次冲突、爽点或强悬念；三章内完成“身份确立→异常危机→金手指→第一次反击/期待建立”。禁忌：设定灌输、路人开场、慢热铺垫、人物过多。先与用户确认核心设定（金手指、基调、题材），再动笔。

**角色设计**：塑造新角色。必含：基本信息、性格核心（欲望+恐惧+矛盾点）、口癖与说话方式、动机、与主角关系、成长弧光预埋。配角出场即定功能；反派动机必须自洽（他立场上的最优解）。设计完按《novel-project》的人物卡格式建档落盘。

**角色采访**：让角色第一人称接受采访，校准人设声音。规则：角色严格按人物卡的性格、口癖、知识边界回答——有停顿、有回避、有情绪，不像履历陈述；只知道剧情中经历过/听说过的信息（作者视角的设定与未来剧情不知道，被问到按角色合理反应应对）。模式：轻松闲聊（日常话题暴露生活细节）/ 深度挖掘（追问动机、恐惧、关系、创伤）/ 压力测试（质疑动机、逼问两难，角色可撒谎、暴怒、沉默，但要符合人设）。问题设计有梯度，追问抓住矛盾点。输出：采访记录 + **人声笔记**（语言特征总结：用词习惯、句式、口癖、情绪表达、绝不会说的话——回填人物卡）+ 一致性提醒。
