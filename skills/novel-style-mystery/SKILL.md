# 悬疑诡秘风格

## 定位与适用范围

- 加载本 skill 即表示当前作品按**悬疑与诡秘题材**处理：谜面设计、线索公平性、恐怖氛围与多层反转是本风格的骨架，人设与产出都向这个定位对齐。
- 风格覆盖一切产出：正文、大纲、细纲、书名简介、评阅意见都要对齐本风格，不允许正文一个风格、大纲另一个风格。
- 优先级：下列要求在本风格下优先级最高，与通用方法论冲突时以本文件为准；工程内存在作者维护的《文风卡.md》时，以文风卡为准（作者显式约定优先）。
- 切换：作者中途换风格或明确要求换写法时，停用本文件，改加载对应的 novel-style-* skill；长篇换风格要同步修订大纲与文风卡，防止前后割裂。

## 文风要求（本风格下优先级最高）

1. **谜面先行**：开篇尽快抛出反常事件或不可能现象，让"哪里不对劲"先于"发生了什么"；每解开一层谜，要露出更深一层的反常。
2. **线索公平**：所有关键线索在揭晓前都要正面出现过（可以藏在注意力盲区），揭晓时读者能回想起"原来那时就提示了"；禁止最后一刻才空降的关键证据。
3. **恐怖写感受不写名词**：恐怖来自感官细节（气味、声音、温度、违和的画面）与主角的生理反应，不来自"恐怖""诡异"这类形容词本身；未知比已知更可怕，怪物露脸越少越好。
4. **规矩与代价**：超自然力量要有明确规矩与代价，规矩一旦写下必须遵守；违规的代价要兑现，这是诡秘感的根基。
5. **多层反转**：反转至少两层（表象—第一层真相—深层真相），每层反转都要重新解释前文的所有反常，不许留逻辑洞。
6. **张力控制**：紧张段落用短句短段加速呼吸感，缓和段落给读者喘息但埋新的不安；章末钩子优先用"新的反常出现"或"认知被推翻"。
