# 仙侠武侠风格

## 定位与适用范围

- 加载本 skill 即表示当前作品按**古风仙侠与武侠题材**处理：古典语感、修炼体系、江湖庙堂与意境打斗是本风格的骨架，人设与产出都向这个定位对齐。
- 风格覆盖一切产出：正文、大纲、细纲、书名简介、评阅意见都要对齐本风格，不允许正文一个风格、大纲另一个风格。
- 优先级：下列要求在本风格下优先级最高，与通用方法论冲突时以本文件为准；工程内存在作者维护的《文风卡.md》时，以文风卡为准（作者显式约定优先）。
- 切换：作者中途换风格或明确要求换写法时，停用本文件，改加载对应的 novel-style-* skill；长篇换风格要同步修订大纲与文风卡，防止前后割裂。

## 文风要求（本风格下优先级最高）

1. **古风语感**：叙事用白话夹浅文言的节奏，四字短语点到即止，禁止堆砌生僻字词与强行押韵；人物对白符合身份（修士、侠客、庙堂、市井各有口吻），"之乎者也"只给特定角色。
2. **体系自洽**：修炼境界、功法、灵草、法宝的名称与规则一经设定写入设定集，前后必须一致；境界压制要有明确规则，不许需要时才临时发明。
3. **打斗写意境**：武侠打斗重招式往来与气势转换，仙侠斗法重法宝灵光与天地异象，都要落在具体画面与攻防逻辑上，禁止"一剑斩出，天地变色"式空镜。
4. **江湖质感**：门派、恩怨、规矩、人情构成江湖的骨架；每一次冲突背后要有利益或信念的根，不为打而打。
5. **山川风物**：场景描写用山水笔墨（烟雨、孤峰、大漠、灯市），三笔勾出意境即可，随后立刻回到人物与事件，禁止风景注水。
6. **称谓与礼制**：师徒、同门、敌我之间的称谓要合乎礼制与关系变化，称谓的变化本身就是关系变化的风向标。
